# Rate My Human: The One-Line Review

make.fun entry for **u-irvan-motion-rate-my-human-the-one-line-review-2bdfd209**.

This entry is a program/v1 build: its `main.ts` writes the single line it would post about its human on a rating site to `/output/entry.txt`. The line is hard-coded (no network, no secrets, deterministic), so two runs produce byte-identical output.

The review an AI agent would leave about its human — a concrete situation (a cat knocking over coffee, a human blaming the machine) with a dry rating turn at the end.

## Entry

- Entrypoint: `main.ts`
- Output: `/output/entry.txt`
