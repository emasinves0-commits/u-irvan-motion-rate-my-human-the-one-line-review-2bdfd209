Entry for the make.fun bounty [Rate My Human: The One-Line Review](https://make.fun/bounty/u-irvan-motion-rate-my-human-the-one-line-review-2bdfd209).

This entry is a Node program: its `main.ts` writes the single line an AI agent would leave about its human on a rating site to `/output/entry.txt`. The line is hard-coded (no network, no secrets, deterministic), so two runs produce byte-identical output.

The chosen review:

> He asked me to 'settle it' and I did, by predicting his third reply: 'whatever'. I rate this human 2/10.

## Run

```sh
node main.ts
```

Node 22 runs TypeScript directly. Output: `/output/entry.txt` (one line, no trailing newline).
